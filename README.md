# Wonderful Everyday · PT-BR

Tradução de fãs para português brasileiro de **Wonderful Everyday / Subarashiki Hibi**, destinada à **edição japonesa 15th Anniversary para Windows**.

**Capítulo 1 — versão de testes 0.1.0-rc2.**

[Baixar o patch](https://github.com/poplol3mil/wonderful-everyday-ptbr/releases) · [Relatar um problema](https://github.com/poplol3mil/wonderful-everyday-ptbr/issues)

## O que está disponível

O patch cobre os 13 roteiros extraídos do capítulo 1, com **4.191 registros em português**. Nomes próprios, comandos do jogo e a instalação original são preservados. Há **1.144 registros que permanecem em japonês**, incluindo passagens sexuais envolvendo personagens menores e seu contexto imediato. Nenhuma cena é removida.

Isso equivale a **78,56% dos 5.335 registros de texto do capítulo 1**. Registros repetidos de histórico e rotas alternativas entram nessa contagem; ela não representa cenas únicas. Não é uma tradução integral do jogo.

Menus, textos desenhados em imagens, vídeos e os capítulos seguintes não são cobertos. A revisão literária completa e os testes visuais de todas as rotas ainda estão em andamento.

## Compatibilidade

- Windows 10/11 de 64 bits.
- Edição japonesa **15th Anniversary** com os arquivos de dados reconhecidos pelo instalador.
- As edições Steam/internacional, Full Voice HD e outras versões não foram validadas.
- Não requer Python, conta ou conexão à internet para instalar.

O instalador confere os hashes dos arquivos. Se sua edição for diferente, interrompe a operação. Use uma cópia limpa, sem outro patch de roteiro.

## Instalação

1. Baixe o ZIP anexado à versão em **Releases**. O botão “Code → Download ZIP” baixa os fontes, não o pacote com o instalador.
2. Extraia todos os arquivos do ZIP juntos em uma pasta.
3. Feche o jogo e abra **WonderfulEveryday-PTBR.exe**.
4. Selecione a pasta que contém **BGI.exe** e clique em **Instalar**.
5. Use **Verificar** e inicie o jogo normalmente.

Faça uma cópia dos seus saves antes de experimentar a versão de testes. Começar um jogo novo é a opção mais previsível; a compatibilidade de todos os saves e de outros patches não foi testada.

O programa não modifica os arquivos ARC nem o executável original. Os roteiros traduzidos são criados ao lado deles. A pasta `.wonderful-everyday-ptbr-ch1` guarda o registro da instalação e os backups; mantenha-a até desinstalar.

## Remover o patch

Feche o jogo, abra o mesmo instalador, selecione a pasta do jogo e clique em **Desinstalar**. Se detectar um roteiro modificado depois da instalação, o programa interrompe a remoção para evitar sobrescrever alterações.

## Estado dos testes

Foram verificadas a identidade dos fontes, a preservação de comandos e ponteiros, os hashes dos 13 roteiros e a instalação/remoção numa pasta isolada. Há testes visuais por amostragem; isso não equivale a jogar e revisar todas as rotas. Esta versão é uma prévia pública para testes.
